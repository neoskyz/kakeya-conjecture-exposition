# Kakeya Conjecture Exposition

A reader's guide to OpenAI's proof of the Kakeya set conjecture, with a check of its Lean statement.
Written for readers who know calculus but not harmonic analysis.

Author: Zinan Xing

Essay (PDF): [kakeya-conjecture-exposition.pdf](kakeya-conjecture-exposition.pdf)

Problem page: [MathDB #315983](https://mathdb.com/p/315983/kakeya-conjecture)

This is an exposition, not a new result: all mathematics is due to the cited authors.
The source is a preprint that has not been refereed; the essay says what is claimed, what the Lean statement says, and what remains open.
Prepared with the assistance of AI.
